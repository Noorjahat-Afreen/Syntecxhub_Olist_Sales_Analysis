# Olist E-Commerce Sales Analysis

## Project Overview
This project analyzes historical Brazilian e-commerce data from Olist to understand sales performance, product categories, customer reviews, regional sales, and delivery performance.

## Project Objectives
- Analyze sales and order volume.
- Identify top-performing product categories and states.
- Understand customer review ratings.
- Evaluate delivery performance.
- Create visualizations and export analysis tables.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Google Colab
- Jupyter Notebook

## Dataset
Source: [Olist Brazilian E-Commerce Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

The dataset contains historical e-commerce records, primarily from 2016–2018. It is public historical data, not live company data.

## Key Findings
- Total item sales: R$ 13,591,643.70
- Orders: 98,666
- Items sold: 112,650
- Highest-sales state in the earlier analysis: São Paulo (SP)
- Five-star reviews: 57,328
- On-time or early deliveries: 91.89%
- Late deliveries: 8.11%

## Methodology
1. Load and clean the dataset using Pandas.
2. Merge relevant order, item, product, customer, and review data.
3. Calculate sales and order metrics.
4. Analyze customer reviews and delivery performance.
5. Create charts and export analysis tables.

## Important Notes
Sales represent the sum of product item prices, not company profit. Delivery percentages are calculated only for orders with both actual and estimated delivery dates available. Verify all reported figures against the final source code and dataset before submission.
